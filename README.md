# ProjectManagementSystem (Система управления проектом)

# Управление
- Стрелка вверх - курсор на одну строку выше
- Стрелка вниз - курсор на одну строку ниже
- Enter - ввести текст/пропустить сообщение об ошибке
- Стрелка влево - вернутся на прошлое окно/передвижение во время заиси данных

# Технологии
- .Net 8.0
- C#

# Особенности
- DI
- Использование Dapper
- Хеширование данных пользователей
- Есть логирование действий
